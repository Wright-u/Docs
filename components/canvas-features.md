# Canvas UI

## Entities Prespective

### Whiteboard

The space that holds everything

### Element

The box that holds information about its entity, including (assuming all elements have names and titles):

- Component
  * Class
    * attribute
    * method
  * Method
    * parameters
    * return types

* Connection
  * source
  * destination
  * source tags
  * destination tags
  * source link type
  * destination link type

## Sequence Perspective

### Timeline

The space that holds a scenario

### Actor

The entity that has the invoke interface

### Call

The invokation from an actor to a method in antoher actor
